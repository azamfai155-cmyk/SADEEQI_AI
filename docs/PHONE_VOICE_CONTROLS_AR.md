# التحكم بالهاتف صوتياً — صديقي

## الحالة
تضيف هذه النسخة مجموعة أوامر محلية محددة تعمل دون إرسالها إلى نموذج الذكاء الاصطناعي. يستقبلها كل من حقل المحادثة وجلسة الميكروفون الظاهرة التي يبدأها المستخدم.

## أمثلة أوامر مدعومة
- «افتح واتساب»، «افتح يوتيوب»، «افتح فيسبوك»، «افتح إنستغرام»، «افتح تيليجرام»، «افتح كروم»، «افتح خرائط جوجل».
- «افتح الإعدادات»، «افتح الواي فاي»، «افتح البلوتوث».
- «افتح الكاميرا»، «افتح ملفاتي».
- «ارفع الصوت»، «خفض الصوت» (صوت الوسائط).
- «اضبط منبه الساعة ٧:٣٠» (صيغة 24 ساعة).
- «اتصل على 777123456»: يفتح شاشة الاتصال والرقم جاهز، ولا يجري المكالمة تلقائياً.
- «اكتب رسالة الى 777123456 نص مرحبا»: يفتح تطبيق الرسائل بنص جاهز، ولا يرسل الرسالة تلقائياً.

## حدود Android والأمان
- الميكروفون لا يعمل دائماً؛ يبدأ فقط عندما يضغط المستخدم زر بدء المحادثة الصوتية، وتظهر إشعارات خدمة foreground مع زر إيقاف.
- فتح تطبيق أو إعداد نظام يتم عبر Android intents. قد يمنع Android فتح شاشة جديدة إذا كان التطبيق في الخلفية؛ عندها افتح صديقي أو اضغط إشعار الجلسة ثم أعد الأمر.
- الاتصال والرسائل والمنبه تفتح واجهات النظام للمراجعة والتأكيد. لا توجد مكالمات أو رسائل صامتة.
- لا يوجد تحكم عام بالنقر داخل أي تطبيق، ولا تجاوز لقفل الشاشة، ولا تغيير صامت لصلاحيات النظام، ولا تنفيذ أوامر إدارية/حذف.
- إعداد Wi-Fi وBluetooth يفتح صفحة إعدادات النظام؛ لا يحاول تجاوز قيود Android لتشغيل/إيقاف الراديو مباشرة.
- قائمة التطبيقات المتاحة محددة في parser؛ التطبيقات غير الموجودة أو غير المدعومة لن تُفتح.
- لا تمنح خدمة Accessibility أو Device Admin صلاحيات واسعة لمجرد تفعيل هذه الأوامر.

## التحقق
تشمل اختبارات الوحدة التعرّف على فتح التطبيقات، إعدادات Wi-Fi، الأرقام العربية للمنبه، تجهيز الاتصال والرسائل، ورفض النصوص غير المطابقة. يجب تشغيل CI وبناء APK وتجربة الأوامر على جهاز Android فعلي قبل اعتبارها معتمدة.
