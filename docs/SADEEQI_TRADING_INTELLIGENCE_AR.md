# SADEEQI TRADING INTELLIGENCE — تنفيذ مرحلي

## المرحلة الأولى الموجودة في التطبيق

- تبويب «التداول» ضمن القائمة الرئيسية.
- مكتبة دروس تحفظ عنوان الدرس والقناة والرابط والملاحظات/التفريغ في EncryptedMemory (Room + Android Keystore AES-GCM).
- حقول مصدر منفصلة حتى لا تختلط ملاحظات المستخدم بمعلومات مصدر غير متحقق.
- قاموس أولي لمفاهيم SMC/ICT مع اختبار تعليمي بسيط.
- حاسبة مخاطرة نقدية وحجم مركز بوحدات نظرية.
- حاسبة Risk/Reward.
- حاسبة إحصاءات لنتائج Backtest اليدوية: عدد الصفقات، Win Rate، Profit Factor.
- اختبارات وحدات للحسابات.

## ما لا تدعيه هذه المرحلة

- لا يوجد تكامل YouTube API أو استخراج تلقائي للتفريغ. ألصق النص المتاح قانونياً وسجل رابط الفيديو والقناة.
- لا يوجد بث أسعار أو تحليل شارت حي؛ لم تتم إضافة مزود بيانات سوق أو مفتاح API.
- لا يوجد Backtesting على شموع تاريخية، ولا Drawdown أو رسوم أو انزلاق سعري. الحاسبة الحالية تلخص نتائج تدخلها يدوياً فقط.
- لا تنشئ إشارات شراء/بيع أو توصيات تنفيذية.

## المرحلة التالية المقترحة

1. YouTube Data API للبحث في القنوات والفيديوهات العامة، مع مسار استيراد transcript فقط عند توفره قانونياً ومن مصدر يدعم ذلك.
2. موصلات بيانات سوقية معروفة حسب السوق (مثل Twelve Data أو Alpha Vantage أو مزود الوسيط)، مع إظهار الرمز والمنطقة الزمنية ووقت آخر تحديث وحدود الخطة.
3. مخزن شموع OHLCV وتطبيع البيانات، ثم أدوات بنية السوق والسيولة وFVG وPOI مع قواعد قابلة للشرح.
4. محرك Backtest على بيانات شموع يتضمن spread/commission/slippage، منع look-ahead bias، تقسيم in-sample/out-of-sample، وتقرير drawdown وexpectancy وprofit factor.
5. مدرب تفاعلي يربط الدروس بالمفاهيم والأسئلة وسجل أخطاء المتعلم.
6. Paper trading وتنبيهات؛ لا تداول حقيقي في هذه المرحلة.

## ضوابط الأمان والجودة

- مفاتيح مزودي البيانات تحفظ في الخادم أو مخزن أسرار، ولا تُضمّن في APK.
- لا تحفظ API keys بصلاحية سحب أو تداول. Paper trading أولاً.
- كل ادعاء تعليمي مرتبط بالقناة/الفيديو/الرابط/النص وتاريخ الاستيراد.
- كل إحصاء يعرض حجم العينة والافتراضات؛ لا تُستنتج أرباح مستقبلية من نتائج تاريخية.
